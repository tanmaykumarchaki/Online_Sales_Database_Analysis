# Online_Sales_Database_Analysis
This project performs data analysis on an e-commerce sales dataset stored in a CSV file, which is imported into an SQLite database. The notebook explores total quantities, revenues, profits, and visualizes category-wise performance using SQL queries and Python.

## Objective

To derive meaningful business insights from raw sales data using SQL queries and visualize key metrics with Python.

## Tech Stack

- **Python**: Data manipulation and visualization
- **pandas**: Reading and processing CSV data
- **sqlite3**: Querying the data from an in-memory SQL database
- **matplotlib**: Plotting insights
- **Jupyter Notebook**: Development environment

## Key Features

- Convert CSV data into a SQL database table
- Execute SQL queries on the `Sales` table to calculate:
  - Total quantity sold
  - Best-selling product category
  - Total revenue
  - Average and total profit
- Visualize revenue by category using bar charts
